> GitHub Pages 放純前端網頁、iOS 捷徑負責「滑到就收」。換的是腦——
> 地圖存店名座標，食譜存食材做法，這裡存的是**能不能拿來用、原始碼在哪**。
>
> ⚠️ 這個 repo 之後會是公開的，`apps-script.gs` 裡的 `SS_ID` 與 `SECRET` 要維持**佔位符**，
> 真值只記在本機 `~/.claude/skills/link2lab/SKILL.md`。


## 設定步驟

以下 7 步**需要你本人的 Google／GitHub 帳號**，我沒有權限代做。每步都附「做對了會看到什麼」。
全部做完，把最後那幾個值告訴我（清單在文末），我補進設定檔就能開始跑。

## 1. 建試算表

1. 開 https://sheets.new
2. 左上角檔名改成 **`link2lab_靈感庫`**
3. 從網址列複製 fileId：`docs.google.com/spreadsheets/d/`**`這一長串`**`/edit`

✅ 做對了：你手上有一串大約 44 個字的 fileId。

**不用手動建欄位**，第 3 步會自動建好。

## 2. 貼上並部署 Apps Script

1. 在剛才的試算表：上方選單 **擴充功能 → Apps Script**
2. 把編輯器裡原有的 `function myFunction() {}` 整個刪掉
3. 打開本專案的 [apps-script.gs](apps-script.gs)，**全部複製貼上**
4. 在編輯器裡**搜尋 `SS_ID`**，改它和下一行的 `SECRET`（約在第 12、13 行，前面都是註解）：
   - `SS_ID` ← 填第 1 步的 fileId
   - `SECRET` ← 自己想一個密語（**不要直接照抄範例** `MYLAB2026`），跟另外兩個專案的也要不一樣
5. 存檔（Cmd+S）
6. 右上角 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」→ 第一次會要求授權，選你的帳號 →「進階」→「前往…（不安全）」→ 允許
7. 複製最後給你的 **網頁應用程式網址**（`https://script.google.com/macros/s/AKfy.../exec`）

✅ 做對了：你手上有一條 `/exec` 結尾的網址。

> ⚠️ 之後若要改程式碼，一定要走「管理部署作業 → 鉛筆圖示 → 版本選新版本」，
> **不要**再按「新增部署作業」——那會產生新網址，捷徑就失效了。

## 3. 一鍵建立分頁與欄位

把下面這行的 `<端點>` 和 `<密語>` 換成你的值，貼進瀏覽器網址列打開：

```
<端點>?token=<密語>&action=setup
```

✅ 做對了：畫面顯示 `ok: 分頁「待處理」與「靈感」已就緒`，回試算表會看到兩個分頁、欄位都建好了。

## 4. 把「靈感」分頁發布成 CSV

1. 試算表：**檔案 → 共用 → 發布到網路**
2. 左邊下拉選 **「靈感」分頁**（不要選「整份文件」）
3. 右邊格式選 **逗號分隔值 (.csv)**
4. 按「發布」→ 確定
5. 複製產生的網址（長得像 `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=...&output=csv`）

✅ 做對了：那條網址貼進瀏覽器會下載或顯示一堆逗號分隔的文字。

## 5. 把 CSV 網址填進網頁

**這步直接把網址貼給我，我幫你改**——你不用碰程式碼。

想自己改也可以：用純文字編輯器（Mac 內建「文字編輯」或 VS Code）打開 [index.html](index.html)，
搜尋 `CSV_URL`，把那一行引號內的「請貼上發布後的 CSV 網址」整串換成第 4 步的網址，存檔。

✅ 做對了：用瀏覽器直接打開 index.html（網址列**不要**加 `?csv=`），
看得到你試算表裡的資料；還沒收藏任何東西時會顯示「📭 還沒有收藏任何靈感」（這也是對的）。

## 6. 上線網頁（GitHub Pages）

> ⚠️ **唯一的禁忌：不要把填了真實密語的 `apps-script.gs` 上傳。**
> 密語等於你試算表的寫入權，進了 Public repo 別人就能亂寫。
> 本專案版控的是**佔位符版本**（第 2 步你是在 Google 的編輯器裡填真值，本機這份不用動），
> 所以整個資料夾上傳是安全的；但你如果自己在本機填過真值，就只上傳 `index.html`。

1. 到 https://github.com/new 建 repo，名稱 `link2lab`，選 **Public**
2. 進 repo → **Add file → Upload files** → 把 `index.html`（和其他檔案）拖進去 → Commit
3. repo 的 **Settings → Pages** → Source 選 `Deploy from a branch`，分支選 `main`／`/(root)` → Save
4. 等一兩分鐘，網址是 `https://<你的帳號>.github.io/link2lab/`

✅ 做對了：打開網址看到「🧪 我的技術靈感庫」，因為還沒有資料會顯示空清單（正常）。

## 7. 建 iOS 捷徑

**要新建一個**，不能沿用另外兩個（端點不同）。最快是**複製**現成的再改：

1. 捷徑 App → 找到「加入食譜庫」→ 長按 → **複製**
2. 改名為 **「加入靈感庫」**
3. 進去編輯，把「取得 URL 內容」那步的網址改成：
   `<端點>?token=<密語>&url=` 後面接**分享的連結那個變數**（原本接哪個就接哪個，不要動它）
4. 捷徑設定裡確認「在分享工作表中顯示」是開的

✅ 做對了：在 Threads 滑到一篇文章 → 分享 → 選「加入靈感庫」→ 試算表「待處理」分頁多一列。

## 目前的限制（先講清楚）

- **Threads 只對爬蟲 UA 吐內容**：用一般瀏覽器 UA 抓回來是空殼（實測 2026-10-22），
  skill 裡已改用 `facebookexternalhit` UA，這點跟 reel2recipe 不同。
- **Threads 貼文的連結常常抓不到**（實測）：curl 只拿得到貼文**文字**，拿不到附件連結；
  很多人的連結是放在影片畫面裡或留言區。遇到這種我會去開貼文的 `/embed` 頁（不用登入）、
  必要時讀影片畫面上的網站名稱，**再 curl 那個網站確認存在才採用**，確認不了就留空問你。
- **Medium 會擋機器抓取**（實測回 403）。遇到 Medium 連結我會標成「待確認」並請你貼內文，
  **不會憑標題猜內容編一筆給你**。
- **星數是收錄當下的快照**，不會自動長。要回補時跟我說「更新 link2lab 星數」。
- 只讀文字，不看影片與圖片裡的內容。
